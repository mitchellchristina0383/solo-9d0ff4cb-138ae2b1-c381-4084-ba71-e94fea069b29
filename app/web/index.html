定向探测：核查非授权 DHCP 应答 

    

      对登记端点发送真实 DISCOVER（每轮生成独立事务号 XID 与探测设备身份），
      仅收本轮 XID + 本设备身份且来自对应 UDP 端点的应答；
      可信度按应答来源端点判定——陌生端点即使冒用受信 Server Identifier 也判为冒用，
      不算受信。探测不发 REQUEST、不确认租约；轮次结束/取消后撤销本轮在本服务产生的 OFFER 预留，
      真实设备的 bound 租约不会被触碰，迟到应答不会混入下一轮。
